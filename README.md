# PDF Editor — загрузки

Здесь публикуются установочные файлы **PDF Editor** — настольного редактора PDF для macOS и Windows.
Исходного кода в этом репозитории нет; отсюда же установленное приложение получает обновления.

## Скачать

Последняя версия — на странице [Releases](https://github.com/UkaUkaa/pdf-editor-releases/releases/latest).

| Файл | Система |
|---|---|
| `PDF-Editor-<версия>-mac-arm64.dmg` | macOS, Apple Silicon |
| `PDF-Editor-<версия>-mac-x64.dmg` | macOS, Intel |
| `PDF-Editor-Setup-<версия>-win-x64.exe` | Windows 10/11, x64 |

Файлы `latest.yml`, `latest-mac.yml` и `*.blockmap` нужны механизму обновления, скачивать их вручную не требуется.

## Перед установкой

- Сборки не подписаны сертификатом разработчика.
  - **macOS:** при первом запуске откройте приложение через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
  - **Windows:** SmartScreen предупредит о неизвестном издателе — выберите «Подробнее → Выполнить в любом случае».

## Обновления

- **Windows:** приложение само скачивает новую версию и предлагает перезапуск.
- **macOS:** приложение сообщает о новой версии и открывает эту страницу; новую версию нужно скачать и установить вручную.
- Автоматическую проверку можно отключить в параметрах приложения. Кроме проверки и загрузки обновлений приложение к сети не обращается и документы никуда не отправляет.
